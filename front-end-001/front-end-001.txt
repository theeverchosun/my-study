flex와 gird의 차이점


 차원(Dimension)의 차이
Flexbox (1차원 배치):

가로(행) 또는 세로(열) 중 하나의 방향으로만 요소들을 배치합니다.

요소가 줄바꿈(flex-wrap: wrap)되더라도, 다음 줄로 넘어간 요소는 이전 줄의 위아래 열 위치와 정렬을 공유하지 않고 독립적으로 배치됩니다.

Grid (2차원 배치):

가로(행)와 세로(열)를 동시에 제어합니다.

바둑판이나 격자 판을 먼저 짜고, 그 구획에 맞춰 요소들을 딱 맞게 배치할 때 사용합니다.

Flexbox                                       grid

 1차원 (가로 또는 세로)	              2차원 (가로와 세로 동시)
기준	내용(Content) 중심 배치	레이아웃(Layout) 중심 배치
주요 목적	컴포넌트 내부 정렬     웹 페이지 전체 틀 구성, 격자형 갤러리
               소규모 일렬 배치
핵심 속성	flex-direction,                 grid-template-columns, grid-template-rows, gap
           justify-content, align-items       


언제 무엇을 써야 할까?
Flexbox를 쓰면 좋은 경우

네비게이션 바 메뉴들처럼 요소를 일렬로 정렬할 때

카드 컴포넌트 내부의 아이콘과 텍스트 수직 중앙 정렬

요소의 개수나 크기가 불확정하여 콘텐츠 크기에 맞춰 유연하게 변해야 할 때

Grid를 쓰면 좋은 경우

사진 갤러리나 상품 목록처럼 가로/세로 규칙적인 바둑판 배치가 필요할 때

대시보드나 웹사이트 전체 레이아웃 (헤더, 사이드바, 본문, 푸터 구역 분할)

요소가 여러 행과 열에 걸쳐 차지해야 할 때 (grid-column: span 2 등)
