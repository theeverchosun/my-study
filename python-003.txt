1 AI 머신러닝 딥러닝

세 개념은 포함 관계

인공지능 (AI)
 └─ 머신러닝 (ML)
     └─ 딥러닝 (DL)

인공지능	사람의 지능적인 행동(판단, 인식, 추론)을 컴퓨터가 흉내 내게 하는 기술 전체	규칙 기반 챗봇, 체스 프로그램, 머신러닝·딥러닝 전부
머신러닝	사람이 규칙을 직접 짜지 않고, 데이터에서 규칙을 스스로 학습하는 방법	주가 상승/하락 분류, 자전거 연체 예측, 스팸 메일 분류
딥러닝	머신러닝 중에서 여러 층의 인공신경망을 쓰는 방법	이미지 인식, 음성 인식, 번역, ChatGPT 같은 언어 모델

핵심 차이

전통적인 프로그래밍(규칙 기반 AI): 사람이 규칙을 직접 만듬. 예: if 대여시간 > 100: 연체
머신러닝: 데이터와 정답을 주면 모델이 규칙을 찾는다. 단, 어떤 특징(피처)을 볼지는 사람이 정함. 수업에서 수익률, 거래량 비율, 이평 대비 같은 피처를 직접 만든 게 이 과정
딥러닝: 특징을 뽑는 일까지 신경망이 스스로 한다. 사진을 그대로 넣으면 "귀 모양, 털 무늬" 같은 특징을 알아서 찾아 고양이인지 판단. 대신 데이터와 계산량(GPU)이 훨씬 많이 필요하다


2 2지도 학습과 비지도 학습

가르는 기준은 정답(라벨, target)



구분	             지도 학습 (Supervised)	                                                     비지도 학습 (Unsupervised)
정답 데이터	있음 (y가 있음)	                                                                    없음 (X만 있음)
목표	                입력으로 정답을 예측	                                                  데이터  안의 구조나 패턴을 발견
학습 코드	               model.fit(X, y)	                                                              model.fit(X)
평가	      정답과 비교 가능 (정확도, 재현율, F1, AUC)                                정답이 없어 평가가 애매함 (실루엣 점수 등)
대표 작업	                   분류, 회귀	                                                     군집화, 차원 축소, 이상치 탐지
대표 알고리즘	ogisticRegression, DecisionTree, RandomForest, KNN, SVM	       K-Means, DBSCAN, PCA


지도 학습은 두 가지로
분류(Classification): 범주를 맞히는것
예: 주가 상승(1)/하락(0), 100분 초과 연체 여부, 스팸 여부
회귀(Regression): 숫자를 맞히는것
예: 내일 주가, 아파트 가격, 대여 시간(분)

비지도 학습 예시
군집화: 정답 없이 대여 기록만 주고 "비슷한 이용자끼리 묶어 줘"라고 하면, 출퇴근형·주말 여가형·장거리형처럼 그룹이 나뉨. 그룹 이름은 사람이 결과를 보고 붙인다
차원 축소(PCA): 피처가 수십 개일 때 핵심 정보만 남겨 2~3개로 줄인다. 시각화하거나 학습 속도를 높일 때 사용
