파이썬에서 가변(Mutable) 객체와 불변(Immutable) 객체의 차이

불변 객체는 한 번 생성되면 내부 값을 바꿀 수 없는 객체입니다. 값을 "변경"하는 것처럼 보이는 연산은 사실 새로운 객체를 만들어서 재할당하는 것입니다.

대표 예: int, float, str, tuple, bool, frozenset
특징: 값이 바뀌면 객체의 id()(메모리 주소)도 바뀝니다.

가변 객체는 생성 후에도 내부 상태를 직접 변경할 수 있는 객체입니다. id()는 그대로 유지됩니다.

대표 예: list, dict, set, 사용자 정의 클래스 인스턴스(기본적으로)


판다스에서 view와 copy의 차이

view는 원본 데이터의 메모리를 공유하는 참조입니다. view를 수정하면 원본도 함께 바뀝니다.
copy는 완전히 독립된 새로운 메모리 공간에 데이터를 복사한 것입니다. copy를 수정해도 원본은 영향받지 않습니다.

안전하게 코딩할때는 원본과 분리된 데이터가 필요할 때 항상 .copy()를 명시적으로 붙이는 것입니다.
