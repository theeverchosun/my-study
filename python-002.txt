브로드캐스팅은 shape이 다른 배열끼리 연산할 때, 작은 배열을 실제로 복사하지 않고 큰 배열에 맞춰 늘린 것처럼 계산하는 규칙입니다.

규칙

두 배열의 차원 수가 다르면, 차원이 적은 쪽의 앞쪽에 크기 1인 차원을 붙여 맞춥니다.
각 차원을 오른쪽(마지막 축)부터 비교해서, 크기가 같거나 둘 중 하나가 1이면 호환됩니다.
크기가 1인 차원은 상대 크기로 늘어나고, 결과 shape은 각 축의 최댓값이 됩니다.
어느 축이든 크기가 다르고 둘 다 1이 아니면 ValueError가 납니다.

import numpy as np

a = np.ones((3, 4))
b = np.array([1, 2, 3, 4])      # (4,)  → (1, 4) → (3, 4)
print((a + b).shape)            # (3, 4)

c = np.array([[1], [2], [3]])   # (3, 1)
print((a + c).shape)            # (3, 4)

x = np.ones((5, 1, 3))
y = np.ones((4, 1))             # → (1, 4, 1)
print((x + y).shape)            # (5, 4, 3)

d = np.array([1, 2, 3])         # (3,) vs (3, 4): 마지막 축 3 ≠ 4
# a + d  → ValueError

pandas에서의 차이점: pandas는 위치가 아니라 라벨(인덱스/컬럼명) 기준으로 정렬(alignment)한 뒤 연산합니다. 라벨이 안 맞으면 NaN이 생깁니다.

python
import pandas as pd
df = pd.DataFrame({'A': [1, 2], 'B': [3, 4]})
s = pd.Series({'A': 10, 'B': 20})

df - s                 # 컬럼 기준으로 맞춰서 뺌 (기본 axis=1)
df.sub(df['A'], axis=0)  # 행 기준으로 빼려면 axis=0을 명시


Data Frame


방식  	기준	                                  슬라이싱 끝 포함?	           용도
df[...]	     컬럼명 / 행 슬라이스 / 불리언	   상황에 따라 다름  	간단한 컬럼 선택, 필터링

주의 사항
① 체인 인덱싱으로 값 수정하지 않기

python
df[df['age'] > 30]['age'] = 0      # ❌ 원본이 안 바뀔 수 있음 (SettingWithCopyWarning)
df.loc[df['age'] > 30, 'age'] = 0  # ✅ loc 한 번에

필터링한 결과를 따로 변수로 받아서 수정할 거라면 .copy()를 붙이는 게 안전합니다. 최신 pandas는 Copy-on-Write 방식이 기본이라 체인 할당이 원본을 아예 바꾸지 않으니, 버전과 상관없이 .loc 한 번에 쓰는 습관이 좋습니다.

② loc과 iloc의 슬라이싱 끝 차이: loc은 끝 라벨을 포함하고 iloc은 포함하지 않습니다. 헷갈리기 가장 쉬운 부분입니다.

③ 정수 인덱스일 때 []의 모호함

python
s = pd.Series([10, 20, 30], index=[2, 1, 0])
s[0]        # 위치 0이 아니라 '라벨 0' → 30
s.iloc[0]   # 위치 0 → 10

인덱스가 정수면 의도를 명확히 하기 위해 loc/iloc을 쓰는 게 좋습니다. 또 df[0]은 0번째 행이 아니라 이름이 0인 컬럼을 찾습니다.

④ 불리언 조건 결합은 &, |, ~ + 괄호

python
df[(df['age'] > 30) & (df['name'] != 'Lee')]   # ✅
df[df['age'] > 30 and df['name'] != 'Lee']     # ❌ ValueError

연산자 우선순위 때문에 괄호를 빼먹으면 에러가 납니다.

⑤ 중복 인덱스: 같은 라벨이 여러 개면 df.loc['a']가 Series가 아니라 DataFrame을 반환할 수 있어서 이후 코드가 깨질 수 있습니다. 라벨 슬라이싱도 인덱스가 정렬되어 있지 않으면 KeyError가 날 수 있으니 sort_index()를 먼저 하는 게 안전합니다.

⑥ 할당 시 인덱스 정렬: Series를 컬럼에 대입하면 위치가 아니라 인덱스 기준으로 맞춰 들어갑니다. 인덱스가 다르면 NaN이 채워지므로, 위치대로 넣고 싶으면 .values나 .to_numpy()로 넣습니다.

python
df['new'] = pd.Series([1, 2, 3])            # 인덱스 0,1,2 vs a,b,c → 전부 NaN
df['new'] = pd.Series([1, 2, 3]).to_numpy() # 위치대로 들어감

이 중에서 특히 더 깊게 보고 싶은 부분(예: MultiIndex 인덱싱, Copy-on-Write 동작)이 있으면 말씀해 주세요.
