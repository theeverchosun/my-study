- DQL
`SELECT` 는 데이터베이스에서 **데이터를 조회하는 명령어**입니다.

데이터를 새로 생성하거나 수정하지는 않기 때문에 일종의 **읽기 전용 작업**이라고 할 수 있습니다. 데이터 조회 시 특정 컬럼 선택할 수 있으며, **필터링/정렬/가공** 등 추가적인 작업을 거쳐서 추출할 수 있습니다. 

**SQL에서 가장 자주 사용되는 명령어로 실무의 대부분이 SELECT 로 이루어집니다.**

예 SELECT EM_NAME FROM EMPLOYEE;  사원 표에서 사원이름을 검색

- DML

DML(Data Manipulation Language, 데이터 조작어)은 테이블의 데이터를 삽입(INSERT), 수정(UPDATE), 삭제(DELETE) 하는 SQL 명령어입니다.


INSERT 새로운 행 추가  : 테이블에 새로운 행(Row)을 추가하는 명령어입니다

예시 INSERT INTO 테이블명
VALUES (값1, 값2, 값3, ...); 
AND

INSERT INTO 테이블명 (컬럼명1, 컬럼명2, ...)
VALUES (값1, 값2, ...);


UPDATE 기존 데이터 수정   : 테이블에 저장되어 있는 기존 데이터를 수정하는 명령어입니다.

예시

UPDATE 테이블명
SET    컬럼명1 = 변경할값1,
       컬럼명2 = 변경할값2,
       ...
[WHERE  조건식]; -

DELETE 기존 데이터 삭제 : 테이블에서 기존 행(Row)을 삭제하는 명령어입니다.

DELETE FROM 테이블명
[WHERE 조건식]; (조건식이 없을때 모든 테이이블내 데이터가 삭제되니 확인해야함]
 



**DML은 변경 사항 취소가 가능합니다.**



DDL과 달리 DML은 트랜잭션 내에서 실행되므로 `ROLLBACK` (변경 사항 취소)을 통해 이전 상태로 되돌릴 수 있습니다. (*단, 설정에 따라 AUTO COMMIT 이 적용된 경우는 ROLLBACK이 불가합니다.*)

DML 실행 시 순서

1. SELECT 로 대상 데이터 확인
2. DML 실행 (INSERT / UPDATE / DELETE)
3. SELECT 로 결과 확인
4. 문제가 없으면 `COMMIT`, 문제가 있으면 `ROLLBACK'`


- DDL

DDL 이란?

**DDL (Data Definition Language, 데이터 정의어)** 은 데이터베이스에서 **테이블, 뷰, 인덱스 등 객체의 구조**를 **정의/변경/삭제**할 때 사용하는 SQL 명령어입니다.

즉, 데이터(값)가 아닌 **구조(틀)**를 정의하는 언어입니다. 실행 즉시 즉시 적용(`COMMIT`)이 발생하므로 되돌리기(`ROLLBACK`)이 불가능합니다.

- **주요 명령어:** `CREATE` (생성), `ALTER` (변경), `DROP` (삭제)

CREATE : 새로운 테이블 생성
예 CREATE TABLE MEMBER (
	MNO NUMBER,
	MID VARCHAR2(30),
	MNAME VARCHAR2(20),
	EMAIL VARCHAR2(50),
	CREATE_AT DATE
);


ALTER : 테이블의 컬럼을 추가 삭제 수정할때 씁니다.
 
추가 ADD:  테이블에 새로운 컬럼을 추가합니다. 새롭게 추가된 컬럼은 테이블의 맨 마지막 위치에 배치되며, 기존에 있던 행들의 해당 컬럼 값은 자동으로 NULL로 채워집니다.

예시 ALTER TABLE 테이블명 ADD (컬럼명 데이터타입 [DEFAULT 기본값]);

수정 MODIFY : 컬럼의 데이터 타입, 크기, 또는 DEFAULT 값을 변경할 때 사용합니다.

예시 ALTER TABLE DEPT_COPY MODIFY (DEPT_ID CHAR(3));

삭제 DROP : 테이블에서 특정 컬럼을 물리적으로 완전히 삭제합니다. 한 번에 하나의 컬럼만 삭제 가능하며, 테이블에는 최소 한 개 이상의 컬럼이 남겨져 있어야 하므로 모든 컬럼을 다 지울 수는 없습니다.

예시 ALTER TABLE 테이블명 DROP COLUMN 컬럼명

객체를 완전히 삭제하려면 DROP TABLE을 사용해야합니다.
